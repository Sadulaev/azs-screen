# Команда / промпт для добивки UI/UX

Скопируй блок ниже в новый чат Cursor (Agent mode) в этом репозитории.

---

```
Доведи UI/UX цифрового табло МУСТАНГ до пиксель-точного продакшен-вида под Сбер ТВ.

Контекст проекта:
- Репозиторий: mustang_app
- Экран ТВ: `/` и `/display` (frontend/src/pages/DisplayPage.jsx + styles/display.css)
- Админка: `/admin` (frontend/src/pages/AdminPage.jsx + styles/admin.css)
- Две раскладки: `grid-2x3` и `list-logo-left`
- Референсы: тёмное премиум-табло АЗС, золотистые «нефтяные» брызги по углам, белый логотип лошади в щите, пилюли цен с тонкой светлой обводкой, крупная кириллица «ЦЕНЫ НА ТОПЛИВО»

Задачи (только UI/UX, API не ломай):
1. Визуально приблизь display к референсам: фон/атмосфера, брызги/градиенты, типографика, отступы, свечение обводки пилюль, иконки колонки/пламени, логотип.
2. Обе раскладки должны выглядеть «ТВ 16:9» — читаемо с 3–5 метров, без мелкого UI-хрома.
3. Добавь 2–3 спокойных motion (появление цен, лёгкий drift брызг, мягкий glow), без мигания.
4. Админку сделай удобной с телефона: крупные поля цен, превью раскладки, превью фона, понятные статусы сохранения.
5. Если нужно — вынеси SVG логотипа/иконок в отдельные файлы, подключи локальные шрифты или оставь Google Fonts.
6. Проверь мобильную админку и десктопный 1920×1080 display.
7. Не меняй контракты API (`/api/config`, upload, layouts, auth), docker/nginx.

Критерии готовности:
- Скрин display на 1920×1080 выглядит как рекламный экран АЗС, а не «веб-страница».
- Смена layout/фона/цен в админке сразу отражается на display (poll уже есть).
- Нет лишних карточек/дашборд-шума на ТВ-экране.

Сначала кратко план, потом правки в коде, в конце — что открыть для проверки.
```
